## 2. ① 대상지 선정 — 편입 필지와 면적

### 2.1 자료

| 자료 | 출처 | 담긴 정보 |
|---|---|---|
| 필지 도형 | VWorld 2D 데이터 API의 연속지적도(`LP_PA_CBND_BUBUN`) | 필지고유번호(PNU), 주소, 지번, 지목 부호, 개별공시지가와 공시연도 |

구역을 가로·세로 0.01도(약 1km) 격자로 나눠 조회하고, 한 번에 1,000건씩 쪽을 넘겨 받은 뒤 PNU로 중복을 없앱니다.
지목은 지번 끝의 부호(예: "12-3 답"의 "답")에서 읽습니다.

### 2.2 편입 판정과 편입면적

```
편입비율 = (필지 도형과 사업구역 경계가 겹치는 면적) ÷ (필지 도형 면적)
편입면적 = 공부면적 × 편입비율
사업면적 = 편입으로 분류된 필지의 편입면적 합계
```

- 면적은 평면직각좌표계(EPSG:5186, 중부원점)로 바꿔 계산합니다.
- 편입비율이 0.99 이상이면 1.00(전부 편입)으로 봅니다. 지적 도형과 경계선의 미세한 어긋남 때문입니다.
- 편입비율이 **최소 편입비율**(기본 0.05) 미만인 필지는 "제외"로 분류합니다. 사용자가 필지별로 바꿀 수 있습니다.
- 편입면적에 도형면적이 아니라 공부면적을 쓰는 이유는 보상이 토지대장 면적을 기준으로 이루어지기 때문입니다. 도형에서는 비율만 구합니다. 공부면적을 아직 받지 못한 필지는 도형면적을 씁니다.
- 필지가 하나도 없으면 사업면적은 경계 도형의 면적입니다.

검증: 남양주 진건읍 일대 약 8.6㎢(필지 10,386건)에서 편입면적 합계와 경계 도형 면적의 차이는 0.1% 이내였습니다.

## 3. ② 입지현황 — 필지 속성

### 3.1 속성의 출처

| 속성 | 1순위 | 없을 때 |
|---|---|---|
| 지목 | 토지특성(`getLandCharacteristics`) | 연속지적도 지번의 지목 부호 |
| 공부면적 | 토지임야목록(`ladfrlList`) | 토지특성 → 도형면적 |
| 용도지역 | 토지특성의 용도지역1 | 용도지역 레이어와 공간 결합 |
| 이용상황 | 토지특성 | 없음(지목으로 대신 분류) |
| 소유구분 | 토지임야목록 | 미확인 |
| 개별공시지가 | 토지특성 | 연속지적도의 공시지가 |

- **용도지역 결합**: 도시(`LT_C_UQ111`)·관리(`UQ112`)·농림(`UQ113`)·자연환경보전(`UQ114`) 지역과 개발제한구역(`LT_C_UD801`) 도형을 받아, 필지 안쪽의 대표점이 들어가는 구역의 이름을 필지에 붙입니다.
- **상세 조회**: 국가중점데이터 API를 법정동·리 단위로 호출해 한 번에 1,000건씩 받습니다. 같은 동·리의 편입 필지가 20건 미만이면 필지별로 조회합니다. 한 필지에 여러 해의 기록이 있으면 기준연도·기준월·갱신일이 가장 늦은 것을 씁니다.
- 토지특성은 개발제한구역 안의 필지를 용도지역 "개발제한구역"으로 표기합니다. 레이어 결합으로 개발제한구역임을 확인한 필지는 용도지역 뒤에 "(개발제한구역)"을 붙여 둡니다.

### 3.2 집계

- 면적은 편입면적 기준입니다.
- 평균 공시지가는 편입면적으로 가중한 평균이며, 공시지가가 없는 필지는 뺍니다.
- 소유구분은 "국유"가 들어가면 국유, "도유·시유·군유·구유"가 들어가면 공유, 나머지는 사유로 묶습니다.

### 3.3 상위계획

국토종합계획, 수도권정비계획, 광역도시계획, 도시·군기본계획, 광역교통계획은 API로 제공되지 않아 사용자가 검토 내용을 직접 적습니다. 계산에는 쓰이지 않고 보고서에만 들어갑니다.

## 4. ③ 보상비

### 4.1 근거

- 기획재정부 「예비타당성조사 수행 총괄지침」
- KDI 「공기업·준정부기관 사업 예비타당성조사 수행을 위한 일반지침 수정·보완 연구(제2판)」(2018) 제Ⅴ장 제3절 "보상비", 표 Ⅴ-41·Ⅴ-42

지침은 보상비를 세 단계로 추정하도록 합니다. ① 감정평가 자료가 있으면 그것을 쓰고, ② 없으면 필지 정보(지번·용도지역·이용상황·공시지가)를 알 때 공시지가에 보상배율을 곱하며, ③ 필지 정보도 없으면 읍면동 평균지가에 시도별 배율을 곱합니다. 이 프로그램은 필지 정보를 직접 수집하므로 ②의 방식을 씁니다.

### 4.2 산식

```
필지 적용 배율   = (시도별 용도지역 배율 + 시도별 이용상황 배율) ÷ 2
필지 토지보상비  = 편입면적 × 개별공시지가 × 공시지가 시점 보정계수 × 적용 배율
토지보상비(A)    = 필지 토지보상비의 합계 (무상귀속으로 표시한 필지는 0)
지장물 및 기타(B) = A × 사업유형별 비율   (또는 직접 입력한 금액)
직접보상비       = A + B
```

지침은 용도지역 배율과 이용상황 배율을 산술평균해 필지별 배율을 구하는 것이 정확성을 높인다고 설명합니다.
예: 경기도, 자연녹지지역, 이용상황 "답" → (1.92 + 1.77) ÷ 2 = 1.845.

## 5. ③ 조성비 등 총사업비

### 5.1 항목 체계와 간접비 산식

항목은 LH 조성원가 체계를 따릅니다(「택지개발촉진법」 제18조의2, 「공공택지 조성원가 산정기준 및 적용방법」, LH 누리집 "조성원가 산정").

```
총사업비 = 용지비 + 용지부담금 + 조성비 + 기반시설설치비 + 이주대책비
         + 직접인건비 + 판매비 + 일반관리비 + 자본비용 + 그 밖의 비용

직접인건비   = (용지비 + 용지부담금 + 조성비 + 기반시설설치비 + 이주대책비) × 직접인건비율
판매비       = (위 금액 + 직접인건비) × 판매비율
일반관리비   = (위 금액 + 직접인건비) × 일반관리비율
그 밖의 비용 = (위 금액 + 직접인건비) × 그 밖의 비용율
자본비용     = 순투입액의 누적액 × 자본비용률
㎡당 조성원가 = 총사업비 ÷ 유상공급 면적
```

**검증**: LH가 공개한 남양주진접2 공공주택지구 조성원가 산정표(2026년 7월)의 직접비와 제비용률을 넣으면, 직접인건비 421.6억 원, 판매비 79.6억 원, 일반관리비 537.5억 원, 그 밖의 비용 4.3억 원과 조성원가 3,765,161원/㎡가 산정표와 같게 나옵니다(자동 테스트에 포함).

### 5.2 두 가지 관점

같은 내역에서 두 금액을 만듭니다.

| | 조성원가 관점 | 예타 재무 분석 관점 |
|---|---|---|
| 쓰임 | 공급가격(조성원가)의 기준 | ⑥ 재무 분석의 현금유출 |
| 자본비용 | 포함 | 제외 |
| 예비비 | 없음 | 포함 |

- 자본비용을 재무 분석에서 빼는 이유: 지침은 금융비용이 할인율에 이미 반영된 것으로 보아 현금유출에 넣지 않도록 합니다.
- 예비비 = (용지비 + 용지부담금 + 조성비 + 기반시설설치비 + 이주대책비, 부가가치세 포함) × 예비비율. 지침은 재무성 분석의 예비비를 "부가가치세를 포함한 사업비의 10%"로 정합니다.

### 5.3 금액이 만들어지는 순서

```
물량 × 단가 항목 = 물량 × 단가 × 단가 시점 보정계수 × 낙찰률(적용 대상만)
요율 항목        = 기준금액 × 요율          (기준금액은 부가가치세를 더하기 전 금액)
합계             = 공급가액 + 부가가치세(가산 대상만)
```

전체 항목과 초기값은 다음과 같습니다. "방식" 열이 "공통"이 아닌 항목은 선택한 산정 방식에서만 쓰입니다.

### 5.4 방식 1 — LH 공개 조성원가 실적 단가 (기본)

LH는 「택지개발촉진법」에 따라 지구별 조성원가 산정표를 누리집에 공개합니다. 산정표에는 항목별 금액, 면적, 제비용률이 있습니다.
이 프로그램은 산정표 {{DISC_COUNT}}건을 읽어 총사업면적 ㎡당 조성비와 기반시설설치비를 계산해 두었습니다. 읽은 값은 항목 합계가 총사업비와 맞는지, 직접인건비가 산식대로 나오는지로 검증했습니다.

초기 단가의 표본은 **2024년 이후 최초 산정된 30만㎡ 이상 공공주택지구**입니다.

초기값은 ㎡당 단가는 표본의 중앙값(천 원 단위 반올림), 제비용률은 표본 가운데 가장 최근 연도 산정표에서 가장 많이 쓰인 값입니다.

{{BENCHMARK}}

알아둘 점:

- 산정표의 조성비에는 공사비뿐 아니라 설계비·자재비·감리비·각종 부담금이 들어 있습니다. 그래서 이 방식에서는 설계·감리 요율과 부가가치세를 따로 더하지 않습니다.
- 지구별 편차가 큽니다. 특히 기반시설설치비는 광역교통개선대책의 규모에 좌우됩니다. 화면에서 유사한 지구만 골라 중앙값을 다시 적용할 수 있습니다.
- 금액은 각 지구가 조성원가를 산정한 시점의 가격입니다. 분석 기준연도와 차이가 크면 "단가 시점 보정계수"로 보정합니다.
- 제비용률은 지구마다 다릅니다. 사업에 적용할 비율을 알면 요율 표에서 고칩니다.

### 5.5 방식 2 — LH 추정자료 단가 적산

**주택단지 기본시설공사 단가** — 사업면적(총면적 − 보존면적)에 적용

### 5.6 자본비용

LH 산식은 "순투입액의 누적액 × 자본비용률"입니다. 이 프로그램은 다음과 같이 계산합니다.

```
연차별 순투입액 누적액 = 그 해까지의 (사업비 투입액 − 용지 대금 회수액) 합계
자본비용 = (연차별 순투입액 누적액 가운데 0보다 큰 값의 합계) × 자본비용률
```

자본비용이 조성원가에 들어가고, 조성원가가 "조성원가 기준" 용지의 공급가격을 정하고, 공급가격이 회수액을 정하므로 서로 물려 있습니다. 그래서 자본비용이 변하지 않을 때까지 계산을 되풀이합니다. 순투입액에는 예비비와 법인세를 넣지 않습니다.

따라서 자본비용은 ⑤의 사업 일정(투입·공급 시기)과 ⑥의 공급가격에 따라 달라집니다.

### 5.7 농지보전부담금 계산 도우미

```
부담금 = Σ [ min(개별공시지가 × 부과율, ㎡당 상한) × 편입면적 ] × (1 − 감면율)     (지목이 전·답·과수원인 필지)
```

부과율 30%와 상한 5만 원은 화면의 초기값이며, 현행 「농지법」 시행령과 감면 규정을 확인해 고쳐야 합니다. 계산 결과는 단추를 눌러야 사업비에 반영됩니다.

### 8.2 분양수입

```
용도별 분양수입 = 유상공급 면적 × 공급단가
공급단가 = ㎡당 조성원가 × 조성원가 대비 배율     (공급기준이 "조성원가 기준"일 때)
         = 직접 입력한 단가                       (공급기준이 "단가 직접 입력"일 때)
```

초기값은 모든 유상공급 용지가 "조성원가 × 1.0"입니다. 이는 자리를 채워 둔 값이며, 용도별 공급기준(조성원가 연동, 감정가격, 경쟁입찰)은 택지 공급가격 관련 법령·지침을 확인해 넣어야 합니다.

### 8.3 연차별 현금흐름

**유출** — 사업비 항목마다 정해진 "투입 일정"에 따라 연차별로 나눕니다(5.3절 표의 마지막 열).

| 투입 일정 | 배분 방법 | 대표 항목 |
|---|---|---|
| 보상 일정 | ⑤의 연차별 보상 비율 | 용지비, 용지부담금, 이주대책비 |
| 공사 일정 | ⑤의 연차별 공사 비율 | 조성비, 기반시설설치비 |
| 분양 일정 | 연차별 계약 금액의 비율 | 판매비 |
| 투입액 비례 | 그 해의 보상·공사 투입액 비율 | 직접인건비, 일반관리비, 그 밖의 비용, 예비비 |

**유입** — 용도별 분양수입을 ⑤의 대분류별 공급(계약) 비율로 나눈 뒤, 대금 회수 조건에 따라 계약 연도와 그 뒤 연도로 다시 나눕니다. 회수가 사업 기간 뒤까지 이어지면 분석기간이 그만큼 늘어납니다.

일정표의 열 합계가 100%가 아니면 합계를 100%로 환산해 계산하고 경고를 표시합니다.

### 8.4 지표

```
할인계수_t = 1 ÷ (1 + 할인율)^(연도 − 분석 기준연도)

PI   = Σ(현금유입_t × 할인계수_t) ÷ Σ(현금유출_t × 할인계수_t)
FNPV = Σ((현금유입_t − 현금유출_t) × 할인계수_t)
FIRR = FNPV를 0으로 만드는 할인율   (−95% ~ 500% 범위에서 이분법으로 찾음. 부호가 바뀌지 않으면 "산정 불가")
```

**법인세(간이)** — 켜면 (현금유입 합계 − 현금유출 합계)가 양수일 때 그 금액에 세율을 곱하고, 수입이 회수되는 비율대로 연차에 나눠 유출에 더합니다. 실제 세무 계산을 대신하는 간이 방식입니다.

### 8.5 민감도·시나리오·분기점

| 분석 | 방법 |
|---|---|
| 민감도 | 한 변수만 −30% ~ +30%로 바꾸고 전체를 다시 계산한 PI |
| 시나리오 | 용지 공급을 1~3년 늦춘 경우, 할인율을 −1%p, +1%p, +2%p 바꾼 경우 |
| 분기점 | PI가 1이 되는 변수의 증감률 (−90% ~ +400% 범위에서 이분법) |

민감도 변수의 범위:

- 보상비(용지비): 용지비, 용지부담금, 이주대책비에 배율을 곱합니다.
- 조성비·기반시설설치비: 두 구분의 금액에 배율을 곱합니다.
- 공급가격: 모든 유상공급 용지의 공급단가에 배율을 곱합니다.

**해석할 때 주의할 점** — 공급기준이 "조성원가 기준"인 용지는 사업비가 늘면 조성원가가 올라 공급가격도 함께 오릅니다. 모든 용지가 조성원가에 연동되어 있으면 보상비나 조성비가 변해도 PI가 거의 움직이지 않습니다. 감정가격이나 입찰로 공급하는 용지를 "단가 직접 입력"으로 넣어야 사업비 변동의 영향이 드러납니다.
