# 신도시 개발사업 타당성 분석 시스템

국내 신규 신도시(택지·공공주택지구) 개발사업의 타당성을 6단계로 분석하는 프로그램입니다.
설계 배경과 적용 기준은 [plan.md](plan.md)에 있습니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| ① | 대상지 선정 | 지도에서 구역을 그리거나 경계 파일을 올리고, 경계에 걸리는 필지를 수집 |
| ② | 상위계획·입지현황 | 지목·용도지역·소유·공시지가 현황 집계, 현황도, 상위계획 검토표 |
| ③ | 사업비 산정 | 토지세목조서와 공시지가 보상배율로 보상비 산정, LH 조성원가 항목 체계로 총사업비 산정 |
| ④ | 토지이용계획 | 신도시 21곳 사례 비율을 불러와 용도별 비율·면적을 직접 수정, 대안 관리 |
| ⑤ | 기본구상 | 세대수·인구·밀도·기반시설 소요, 구상도(블록), 사업 일정 |
| ⑥ | 재무적 타당성 | 예비타당성조사 지침 기준 PI·FNPV·FIRR, 민감도·시나리오·대안 비교, Excel 보고서 |

## 실행

```bash
uv sync                              # 처음 한 번: 패키지 설치
uv run streamlit run app/main.py     # 브라우저에서 http://localhost:8501
```

## GitHub에서 바로 실행 (Streamlit Community Cloud)

저장소: https://github.com/playground-for-thinker/new-city-plan

`main` 브랜치에 올리면 Streamlit Community Cloud가 자동으로 다시 배포합니다. 처음 한 번만 아래 순서로 연결합니다.

1. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다. 조직 저장소가 보이지 않으면 Streamlit의 GitHub 접근 권한에
   `playground-for-thinker` 조직을 추가합니다(조직 관리자 승인 필요).
2. "Create app" › "Deploy a public app from GitHub"에서 저장소 `playground-for-thinker/new-city-plan`, 브랜치 `main`,
   실행 파일 `app/main.py`를 지정합니다. 아래 주소로 열면 이 값이 미리 채워집니다.
   https://share.streamlit.io/deploy?repository=playground-for-thinker/new-city-plan&branch=main&mainModule=app/main.py
3. "Advanced settings"에서 Python 3.12 이상을 고르고, Secrets에 `.streamlit/secrets.toml.example`의 두 줄을 붙여 넣은 뒤
   `VWORLD_API_KEY` 값을 채웁니다. 인증키는 저장소에 올리지 않습니다.

클라우드에서 쓸 때 알아둘 점:

- 프로젝트 저장 폴더(`projects/`)와 VWorld 응답 캐시는 앱 서버의 임시 디스크에 있어, 앱이 다시 시작되면 사라집니다.
  접속한 사람 모두가 같은 프로젝트 목록을 봅니다. 보관할 분석은 Excel 보고서로 내려받으세요.
- 연속지적도 겹쳐 보기(WMS)는 브라우저가 VWorld에 직접 요청하므로, VWorld 인증키의 서비스 URL에 배포된 앱 주소를 등록해야 보입니다.
  필지 수집·속성 조회·배경지도는 등록 없이 동작합니다.
- 앱을 공개로 두면 접속한 누구나 이 인증키의 호출 한도를 쓰게 됩니다. 비공개 저장소에서 배포한 앱은 초대한 사람만 볼 수 있습니다.

## VWorld 인증키

`.env.example`을 `.env`로 복사하고 키를 넣습니다. 키는 https://www.vworld.kr/dev/v4api.do 에서 발급합니다.

```
VWORLD_API_KEY=발급받은 키
VWORLD_DOMAIN=키 발급 때 등록한 서비스 URL (예: http://localhost:8501)
```

`VWORLD_DOMAIN`에는 포트 번호를 붙이지 않습니다(`http://localhost:8501`로 적으면 인증 오류가 납니다).

키가 있으면 VWorld 배경지도·연속지적도 겹쳐 보기, 주소 검색, 필지 자동 수집, 필지 속성(용도지역·이용상황·소유구분) 조회를 쓸 수 있습니다.
키가 없으면 필지 파일(GeoJSON, SHP ZIP)을 올리거나, **가상 필지(시험용)** 로 전체 흐름을 시험할 수 있습니다.

실제 호출로 확인한 처리 속도(2026-10-03): 약 8.6㎢·필지 1만여 건 구역에서 필지 수집 3초, 용도지역 결합 1초,
필지 속성 조회 30초. 속성은 법정동·리 단위로 한 번에 1,000건씩 받습니다. 받은 응답은 `.cache/vworld.sqlite`에 보관되어
같은 구역을 다시 조회할 때는 호출하지 않습니다(최신 자료로 다시 받으려면 이 파일을 지웁니다).

실제 순서: ① 화면에서 "필지 수집 시작" → ② 화면의 "VWorld에서 필지 속성 보강"에서 "용도지역 결합"과 "상세 조회 시작".
연속지적도만으로는 지번·공시지가만 있으므로, 보상배율을 정확히 적용하려면 상세 조회까지 해야 합니다.

## 사업비 기준 (LH 자료)

조성비·기반시설설치비는 ③ 화면에서 두 방식 가운데 하나로 산정합니다.

| 방식 | 내용 | 근거 |
|---|---|---|
| **LH 공개 조성원가 실적 단가** (기본) | 총사업면적 × ㎡당 실적 단가. 설계·감리·자재·부담금이 들어 있는 금액 | LH 누리집 '조성원가 공개사업지구'의 지구별 조성원가 산정표 22건 (`data/references/lh_cost_disclosures.csv`) |
| **LH 추정자료 단가 적산** | 기본시설공사 단가(지형·규모별) + 공원·녹지 + 추가공종 + 조사·설계·감리·시설부대비 요율 | LH 「2024년도 단지개발사업 조성비 및 기반시설설치비 추정자료」 단가 (`data/standards/lh_unit_costs_2024.yaml`), 요율표 (`fee_rates.yaml`) |

- 실적 단가의 초기값은 2024년 이후 최초 산정된 30만㎡ 이상 공공주택지구 8곳의 중앙값입니다
  (조성비 약 30.1만 원/㎡, 기반시설설치비 약 22.2만 원/㎡). 지구별 편차가 크므로(조성비 약 25만~63만, 기반시설설치비 약 5만~60만 원/㎡)
  화면의 참고표에서 유사 지구를 골라 조정하세요.
- 직접인건비·판매비·일반관리비·그 밖의 비용 요율과 자본비용률의 초기값은 LH 산정표의 최근 제비용률입니다
  (2.00% / 0.37% / 3.25% / 0.03%, 자본비용률 2.52%). 산식은 LH 조성원가 산정 안내를 따르며,
  남양주진접2 산정표(2026.7)의 간접비와 조성원가(3,765,161원/㎡)를 그대로 재현하는 테스트로 확인했습니다.
- 자본비용은 LH 산식대로 연차별 순투입액 누적액 × 자본비용률로 계산합니다. ⑤의 사업 일정과 ⑥의 공급가격에 따라 달라집니다.

**LH 추정자료에 관한 한계**

- 추정자료 원문은 구하지 못했습니다. 원문을 올린 사이트는 회원만 내려받을 수 있었습니다. 적산 방식의 단가는 이 자료를 인용한
  인천연구원 「2025년 인천광역시 지방재정 투자사업 비용산정 가이드라인」의 표에서 옮긴 값이며, 인천연구원이 2024년 12월 기준으로
  물가 보정한 금액이라 LH 원문 수치와 다를 수 있습니다.
- 추정자료의 기본시설공사 단가(약 4.4만~6.2만 원/㎡)는 기본공종만 포함합니다. 이 단가만으로 적산하면 LH가 공개한 실제 조성비
  (약 30만 원/㎡)의 일부에 그치므로, 하천·저류지·전기·통신·구조물·부담금 등을 추가 항목에 넣어야 합니다. 화면에서 실적과 비교해 경고합니다.
- 설계비·감리비·시설부대비 요율은 LH 자체 요율이 아니라 정부 예산편성 기준 요율표입니다.
- 추정자료 원문(공종별 단가, LH 요율)을 보유하고 있으면 `lh_unit_costs_<연도>.yaml`을 같은 형식으로 추가해 교체할 수 있습니다.

## 그 밖에 입력이 필요한 값

- **간접보상비 요율, 용지부담금, 이주대책비** — ③ 화면. 근거 자료가 없어 0으로 두었습니다. 농지보전부담금은 계산 도우미가 있습니다.
- **용도별 공급가격 기준** — ⑥ 화면에서 입력합니다. 초기값은 모든 유상공급 용지가 "조성원가 × 1.0"입니다.
- **공원·녹지 법정 확보 기준** — ④ 화면에서 사업 유형·규모에 맞는 값을 입력합니다. 근거 정리는 `data/references/park_green_rule_notes.md`.
- **보상배율표** — `data/standards/compensation_multipliers_2018.yaml` (2018.4 총괄지침 기준). 최신 판을 확보하면
  같은 형식으로 `compensation_multipliers_<판>.yaml`을 추가하면 ③ 화면에서 선택할 수 있습니다.
- **단가 시점 보정계수** — ③ 화면. 단가 기준시점(실적 2024~2026년, 추정자료 2024년 12월)과 분석 기준연도가 다르면 입력합니다.

주택 밀도(용적률, 세대당 연면적, 세대당 인구), 사업 일정, 세분류 구성비(공원 60 : 녹지 40 등), 농지보전부담금 도우미의 초기값은
프로그램의 가정값이며 화면에서 수정합니다.

## 알려진 한계

- VWorld 자료에 속성이 없는 필지가 일부 있습니다(시험 구역에서 공시지가·이용상황 누락 약 1%). 공시지가가 없으면 같은 지목의
  평균지가로, 이용상황이 없으면 지목으로 대신 계산하고 토지세목조서 비고에 표시합니다.
- 토지특성의 용도지역은 개발제한구역 필지를 "개발제한구역"으로만 표기합니다(바탕 용도지역이 따로 나오지 않음). 보상배율 분류는
  "녹지·개발제한"으로 같아 계산에는 영향이 없습니다.
- 필지가 6,000건을 넘으면 지도에는 경계만 그립니다(집계와 계산은 전체 필지로 합니다).
- 사례 자료의 공원·녹지 비율은 공원+녹지만 집계한 값입니다. 하천·공공공지·유수지는 '기타 공공시설'에 들어 있어,
  고시의 "공원녹지율"이나 「공공주택 업무처리지침」의 공원·녹지 기준(하천 등 포함)과 직접 비교하면 안 됩니다.
- 법인세는 간이 방식(사업 전체 이익 × 세율)이며 기본은 미반영입니다.
- 경제성 분석(B/C), 정책성 분석, 사업수행기관 재무안정성 평가, 블록 자동 배치는 포함하지 않습니다.
